# M16 挖词站点解析器实施计划

依据 `PRD-拉新流水线重建-v1.md` M16；只修改本模块、对应测试、离线样本和 demo。

1. 从安装包 PyInstaller PYZ 只读提取 `business.hot_names_collector` 的站点入口、正则、URL 和阈值；记录与 PRD 冲突之处，以 PRD 验收为准。
2. 为每个 `parse_*` 编写离线 HTML/JSON 样本和期望输出；补充清洗、黑名单、版本归一、请求封装测试，先运行观察失败。
3. 实现纯解析函数、复用的请求辅助函数及站点 `fetch_*`，不增加依赖；Steam 仅使用探测到的本地代理。
4. Python 3.12 运行 M16 测试与独立 demo，报告离线覆盖和未完成的真实站点验证。

## 复核记录

- 原安装包 `百度知道拉新大师.exe` 内的 PyInstaller `PYZ.pyz` 含 `business.hot_names_collector`；读取其 code object 的函数名、常量、正则及 URL。未修改安装包。
- 19 个 `parse_*` 入口各有离线样本；42 个榜单来源在 `sources.json` 映射到对应解析样本，并逐个运行 `fetch_*` 离线测试。19 个解析样本与安装包原函数的输出逐一比对，差异 0。
- PRD 要求 `Photoshop 2024 v25.0 绿色版` 剥离成 `Photoshop`；原安装包函数在该输入上返回原串，因此本实现按 PRD 验收修正。`canonical_key` 对含空格的版本号也按接口语义修正。
- Steam 使用本地代理固定候选端口 7890/7891/7897，加上系统代理中配置的本地端口；代理探针通过后才请求 Steam。此处未验证真实网络。
- 所有 HTML/JSON 样本均为按旧包结构手工构造的离线样本；当前站点页面结构与网络可用性仍需现场验证。
