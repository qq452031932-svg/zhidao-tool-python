# 2026-09-30 知道采集关键词表格导入

## 问题和改动

用户直接导入飞书下载的关键词榜单 XLSX，界面报「无法识别文件编码，请另存为 UTF-8 后重试」。根因是文件选择器允许所有文件，而助手对所有内容无条件执行文本解码。

- 新增 `tools/collect_helper/keyword_files.py`，按扩展名读取 XLSX、CSV、TSV、TXT。只使用内置 Python 标准库，不依赖 Office 或新增 Python 包。
- 识别「热搜索词」「高搜索词」「高消费词」「高转化词」「关键词」「关键字」「搜索词」等表头，仅提取该列；支持共享/内联/富文本、稀疏列、多列表头前的单行标题和无表头单列。单列数据中途出现「关键词」不会误删之前的数据。
- XLSX 读取第一个可见且非空的工作表；多列无法识别、候选词列不唯一、损坏格式明确报错。旧 XLS 暂不支持，提示另存 XLSX，不再误报编码问题。
- 文件选择器和提示列出支持格式。稳定去重后追加到原关键词，重复导入不重复填充。首次导入前仍支持手填逗号分词；成功导入后当前页面按每行一个词处理，提示同步更新，编辑/清空后恢复也保留词内逗号。单元格换行变成空格，仍作为一个关键词。
- 读取期间开始/导入按钮保持忙碌，直到成功、读取失败或断连；失败保留原输入。状态/日志显示来源词列、文件词数、本次新增数和当前总数。
- 沿用 8 MB 文件、单批 10000 个关键词上限；合并已有词后也检查上限，截断时有明确提示。XLSX 解压内容及扫描行数另有边界。
