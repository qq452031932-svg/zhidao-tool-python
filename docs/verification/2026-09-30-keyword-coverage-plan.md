# 模糊采集先覆盖关键词，再补足全局目标

用户明确要求：五词目标十条，先每词至少一条，再补足。沿用最近一月三轮、最多90天、未知日期拒绝及UI不变的已批准约束；仅默认模糊多词的调度改变。目标少于词数时仍尊重目标上限，按输入顺序尽量覆盖不同词；找不到合格且不重复的结果须日志说明，允许其他词补足。

## 设计

- 新增 `lxds/fuzzy_coverage.py`，在现有模糊补量循环前进行覆盖调度；只覆盖原始输入词，领域扩展属于原词，不单独占保底名额。同一去重资源不算多个词命中。
- 近月最多三个句式首页轮次，先各原词，再其扩展；命中的词停止覆盖搜索。未命中词进入90天覆盖阶段，轮流搜索，单查询最多5页，每原词最多30个业务搜索页，避免单个难词无限占用；未找到只说明本轮预算内未命中，不声称全网无资源。
- 覆盖页最多入表一条；正常页面继续利用有界任务缓存。近期已全处理页标记完成；90天无命中且已完整走完的查询标记完成，未消耗完的正常页面留给原补量循环复用，不阻断后续分页。全部可覆盖词已有一条或覆盖预算耗尽后再补总数。
- 复用日期过滤/去重/辅助浏览/风险处理。入表保存原词归属到checkpoint元数据，UI行字段不改；停止回调前记录归属。恢复保留合法且归属可靠的覆盖行，跳过已覆盖词；旧多词断点无归属行不猜测，重搜并记日志。
