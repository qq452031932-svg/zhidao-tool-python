## 实现

| 部分 | 本次行为 |
| --- | --- |
| 精准 | `求{关键词}百度网盘链接`，每词最多两页、三个详情、一个成功收录；十词块内洗牌；摘要优先，真实资源名提取失败回退关键词；全部时间范围。 |
| 模糊 | 原版领域扩展和六个查询句式，最近一月→最近一年→全部；具体名称过滤、日期过滤、每问题首个成功链接；单查询连续五页无新增换查询、30 页复核、60 页结束站内搜索。无密码命中计入原版计数复位语义，但不计为已采行。 |
| 补量 | 默认改为百度 `site:zhidao.baidu.com` 找知道问题并读详情，不再默认采普通百度网页摘要。精准一个变体，模糊最多六个；每变体六页、每页六详情；原版空页、空变体、重复链接、连续十词无新增规则；保留逐条产出。 |
| 解析/去重 | 原版资源名、噪声词、正文容器优先级、标题、删除/空页判别；分享 ID 至少八字符、最近提取码关联；分享 ID 去重忽略协议，名称小写去重，重复名称仍消费分享 ID。 |
| 请求与账号 | 最多两个账号；原版出口分配、可用槽选择、超时 12 秒、最多 30 次、同 URL 重试；原版探针/冷却/继续决策与阅读/长休息节奏。匹配的固定出口直接使用，缺失时回退请求池，遵循原版实际代码。 |
| 恢复/停止 | 兼容旧断点字段及原版字段别名；自然结束清理断点，停止和抛出失败保留逐条保存的结果。失败事件保留已显示行数；风险询问最多 1800 秒；停止后不启动后续代理探测。 |

生产实现位于 `dakazhandian/tools/collect_helper`，核心同步至外层 `lxds`。新增 `collect_engine.py` 分离原版决策，`collection_rules.py` 集中保存规则；现有 WPF 页面和通信协议字段不变。

## 保留的适配差异

- 保留已修好的表格导入、UTF-8/HTML 解码、非法长提取码及中文 URL 边界、完整搜索块边界、逐条显示和可中断等待。
- 原版 Qt 信号改为现有助手 JSON 回调；界面的已采数量始终为实际行数。内部仍保留原版无密码命中的计数语义。
- 原版补量批量返回改为生成器，以保证第一条即时出现、到目标或停止后不预取下一条。
- 保留已有显式时间范围、`LXDS_CLASH_PROXY` 配置及旧断点兼容。UI 默认路径使用原版阶段；bool 详情开关映射为 `auto/off`。
- 停止不会中断已经进入 requests 的单个阻塞调用；它在该调用返回或超时后生效，不再继续后续探测/重试。
