3. 工具栏、多选、作用范围与操作状态绑定；覆盖空结果、所选/全部、取消、失败、忙碌保护、Excel 实际读取与名称/提取码映射、窄宽度布局。
4. 在隔离构建目录运行相关 C# 和 Python 测试，保留当前结果后更新可执行程序；记录实际验证范围。
